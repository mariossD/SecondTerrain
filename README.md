Zombie Survival FPS
A first-person shooter (FPS) game developed in Unity as part of a bachelor thesis project. The player must survive against hostile zombies by exploring the environment, managing ammunition and health, and eliminating enemies.

Project Overview
The game focuses on core FPS mechanics, including player movement, shooting, enemy AI, health management, and a scoring or wave-based survival system.

The main objective is to survive for as long as possible or eliminate all zombies in each wave.

Features
First-person player movement and camera controls

Weapon shooting and reloading system

Ammunition management

Zombie enemy AI with movement, detection, attack, and death behavior

Player health and damage system

Zombie spawning system

Wave-based gameplay

User interface for health, ammunition, score, and game status

Game Over and Victory conditions

Sound effects and animations

Technologies Used
Unity Engine

C#

Unity NavMesh for zombie navigation and pathfinding

Unity Animator Controller for player and zombie animations

Unity UI system for HUD and menus

Unity Physics and Collision system
